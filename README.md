# 📊 HR Operations & Executive Payroll Intelligence System

An end-to-end HR Operations and Payroll Analytics Solution built using **Advanced Excel** and **Power Query**. This project transforms raw employee operational data into automated payslips, executive KPI dashboards, and data quality audit pipelines.

---

## 📌 Project Overview
* **Primary Dataset:** IBM HR Analytics Employee Attrition & Performance (1,470 Records).
* **Core Objective:** Eliminate manual payroll errors, automate net salary calculations, and deliver real-time HR executive insights.
* **Architecture Workflow:** Raw Data $\rightarrow$ Power Query Cleaning $\rightarrow$ Excel Logic & Dynamic Lookup $\rightarrow$ Executive Dashboard & Automated Payslips.

---

## 🛠️ Tech Stack & Key Capabilities
* **Power Query:** Data cleaning, custom column transformations, and automated ETL workflows.
* **Advanced Excel Functions:** Dynamic Lookup & Conditional Logic (`XLOOKUP`, `IFERROR`, `COUNTIF`, `COUNTBLANK`, `ROUND`).
* **Interactive Visualization:** PivotTables, PivotCharts, Slicers, dynamic KPI cards.
* **Data Governance & QA:** Automated audit log tab (`Data_Quality`) verifying zero-duplicates, non-null values, and 100% net payroll reconciliation.
